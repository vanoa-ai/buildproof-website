# BuildProof — nieuwe website

Nieuw ontwerp voor BuildProof, gebouwd op de opbouw van de Installatieflow-kloon (`../installatieflow`), met eigen BuildProof-teksten, huisstijl (blauw/oranje, Montserrat/Nunito), logo en productmockups.

- Live pad: `https://site.buildproof.nl/buildproof-nieuw/`
- Lokaal: `node buildproof-nieuw/server.js` → http://localhost:4000/buildproof-nieuw/
- Afspraken lopen via Calendly (`buildproof-nl/kort-gesprek`), in de popup en op `/scan`.
- Geen externe tracking (geen Meta Pixel, geen chatwidget).
- Huisstijl-aanvullingen en mockup-stijlen: `assets/brand.css`.
