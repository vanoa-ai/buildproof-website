# BuildProof — v4

Ontwerp van `buildproof-nieuw` (opbouw van de Installatieflow-kloon), met uitleggende teksten en de huisstijl uit de BuildProof Brand Guide v1.0: navy `#1b2a3d`, amber `#fece21` als accent (altijd navy tekst), mist-vlakken, alleen Poppins, geen emoji, tagline "Elke stap op de bouw, bewezen."

- Live: `https://site.buildproof.nl/buildproof-v4/`
- Lokaal: `node buildproof-v4/server.js` → http://localhost:4000/buildproof-v4/
- Demo's via Calendly (`buildproof-nl/kort-gesprek`), geen externe tracking.
- Huisstijl en mockups: `assets/brand.css`.

Eerdere versies staan ernaast: `installatieflow/`, `buildproof-nieuw/`, `buildproof-v3/`.
